# Security check: Port the donor-journey motion to the work page

## Verdict
Pass. No security findings. The seven open findings are the design station's (all low).

## Surfaces touched
Static pages (new draft case study, `work-page.html` journey branch, `journey_scene` component, `partials/journey.html`), one new script (`js/journey.js`) and a one-line `head.js` change, a new stylesheet and tokens, two vendored media files, Decap `config.yml` fields, the shots tools (`shoot.mjs`, `serve.mjs`), agent memories, skills and docs. Not touched: `_headers`, `admin/index.html`, workers, crates, D1, Cargo files, `.github`, `.claude/settings.json`, `.claude/agents`, `tools/factory/src`. Proof: `git diff HEAD --quiet -- site/static/_headers site/static/admin/index.html .gitignore .claude/settings.json .claude/agents .github tools/factory/src` printed "unchanged".

## Checklist
- Secrets: ok. The secret grep on `git diff HEAD` found nothing (rc 1). The untracked-files grep (media excluded) found nothing (rc 123). Both `.dev.vars` files are still ignored.
- Output encoding and XSS: ok. The only `| safe` is `page.content` (allowed). The new templates print front matter only through escaped `{{ }}` (step title and body, compare label, value and share, the component's `label`). An added-lines tag and attribute census of `components.html` shows only div/span/p/b/i/em/small/ul/li/figure and SVG shapes (svg/g/path/line/circle/ellipse/rect). It has no script, `on*=`, `href`, `style`, `url(`, foreignObject or entities. I read `journey.js` line by line. It writes text with `textContent` from constants (NAME, EMAIL, PHONE, status words, labels). It changes classes with `classList` and styles with `element.style` / `style.setProperty` (CSSOM, which `style-src 'self'` permits). `setAttribute` sets only SVG geometry (`cx/cy/r/x1..y2`, numbers it computes), `aria-current`, `aria-pressed` and `data-paused`. The forbidden-API grep (innerHTML/outerHTML/insertAdjacentHTML/document.write/eval/new Function/setTimeout/setInterval/setAttribute('style')/cssText/fetch/XHR/import()/URLs/location/cookie/localStorage/postMessage/.src=/href) printed nothing. `data-share` is read with `parseFloat`, falls back to 0 and is clamped to 0-100 before it becomes `--w`. The `head.js` change only adds a fixed class on `pagereveal`.
- Headers and CSP: ok. `_headers` is unchanged. A drafts build to the scratchpad has 0 `style="` in any HTML page. The donation page has no `<script>` without `src` except `application/ld+json`. Its scripts and styles are all same-origin (journey.js, head.js, site.js, journey.css, main.css). The video and poster are same-origin `/images/`, which `default-src 'self'` covers for media. The only outside URLs on the page are the existing GitHub links, the SVG namespace and schema.org. `journey.scss` and the added token lines contain no `url(`, `@import` or `http`. No googleapis/gstatic anywhere in `site/` (the mock-up's Google Fonts links were not ported). The design review's shots, served with the real `_headers`, reported 0 CSP violations.
- Media (byte copies): ok. `sha256sum` gives `64dbd92f...73c7c1` (mp4) and `0974e07c...aa2350` (poster), matching the plan and `design/journey/`. The JPEG starts with `ff d8 ff e0` and ends with `ff d9`. Its segments are only APP0 JFIF, DQT, SOF0, DHT and SOS, with no EXIF, comments or GPS, and 0 trailing bytes. The MP4 box walk (ftyp, moov, free, mdat) consumes all 245,863 bytes. Its only metadata is the encoder tag (Lavf/x264), with no file paths or names.
- Decap fields: ok. `config.yml` adds `extra.journey`: an object holding `steps` (list, min 5, max 5, string and text) and `compare` (string, string, number int 0-100, boolean). They are plain widgets: no raw HTML widget, no new backend or media settings. `admin/index.html` and its pinned script are unchanged. The dev server serves the new config (HTTP 200, `name: journey` present), and the builder confirmed `/admin/` loads with no config error. Every value an editor enters reaches the page escaped, and `share` is clamped again in JS.
- Auth, sessions, CSRF: not applicable. No worker, cookie or auth code changed.
- Database: not applicable. No D1 or migration changes.
- Publishing to git: not applicable. No cms-api changes.
- Dependencies: not applicable. No Cargo or npm changes, and no new third-party asset on the site.
- Agent and tooling safety: ok. `shoot.mjs` passes `--root` inside the `spawnSync` argument array (no shell). The `--scroll` selector goes to `page.evaluate` as an argument, not spliced into code. Fractions are filtered to finite numbers 0-1 before they appear in file names, so no path tricks. `serve.mjs` only gains the `.mp4` type. The new memory notes, lessons and skill lines contain tips (Tera, Playwright with real Chrome via its own launched profile, report chunking). None loosens a guard or reaches outside the repo. The outside package `design/journey/` (untracked, not published) was grepped for agent-directed text, network calls and obfuscation. It contains scene logic and its Google Fonts links only. Nothing addresses agents.
- Privacy: ok. The page holds only invented, labelled sample data (`rina@example.com` is a reserved domain; the phone number is a sequential placeholder). It adds nothing personal about Nows and no analytics or embeds. The page stays `draft = true`, and the normal build has no `work/donation-website/`.
