# Reporting a security problem

Thank you for looking. Please report vulnerabilities privately through this repository's **Security** tab ("Report a vulnerability"), not in a public issue. I'll reply as soon as I can and credit you in the fix if you'd like.

In scope: the site's headers and pages, the two Cloudflare Workers (`workers/decap-oauth`, `workers/cms-api`), and `crates/cms-core`. How the site is protected: [docs/security.md](docs/security.md).
